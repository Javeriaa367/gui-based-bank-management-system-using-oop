1. Project Description

This project is a Smart Bank Management System developed using C++ and Qt Creator GUI framework. The system is based on Object-Oriented Programming (OOP) concepts and file handling techniques to ensure secure and permanent data storage.

The software provides a user-friendly graphical interface that allows administrators to manage banking records efficiently. It supports account creation, updating records, searching customers, transaction handling, and account deletion.

The main objective of this project is to demonstrate the practical implementation of GUI-based application development, OOP principles, and real-world banking system simulation.

2. Objectives

To develop a secure banking system using C++

To implement graphical user interface using Qt

To apply OOP principles in real applications

To store data permanently using file handling

To simulate real banking operations
